# Chaos Tendency — Shenmen / Season of Ghosts   (hook: chaos)
# The Chaos Factor step is ALWAYS ±1 per scene (RAW). This file tunes the LEAN (how readily
# a scene counts as "in control") and notes seasonal FLOORS — not the step.

- start: 5
- control_lean: harsh
  # Folk horror: safety is hard-earned. Count a scene as "in control" (−1 CF) only when the
  # PC decisively ended it on their own terms. Dread, a haunt, a hidden watcher, an
  # unanswered question, or a townsperson lost → the scene was chaotic (+1). When unsure, +1.

- floor:
  # Per-context minimum Chaos Factor (the world stays dangerous in these):
  #  - "Act 1 mindscape / the looping summer day": CF >= 4   (the cycle resists control)
  #  - "First Long Night and the long winter nights": CF >= 4
  #  - "Specterwood / Tan Sugi Monastery / Kugaptee's Grave / any nindoru ground": CF >= 4
  #  - Willowshore proper in a calm interlude has no floor (cozy beats are allowed to breathe)

- flavor: standard
  # Full chaos influence on the Fate Chart. Horror wants the world's volatility to bite.

# Seasonal note (the campaign's arc of dread): summer = wrongness & mystery; fall = mounting
# siege & community strain; winter = scarcity, grief, desperation (consider starting fall/
# winter acts at CF 6 if the prior act ended badly); spring = murder-mystery paranoia
# resolving toward catharsis. The discipline never relaxes; only the genre's "maximal honest
# consequence" shifts (a haunt's victim, a faction turned, a secret exposed, a death).
